DisplayCam 正式更名为 **Mirra · 舞镜**。

**新功能**
- 新名字、新图标：舞者和镜中的自己，指尖相触
- 自动更新：每天检查 GitHub 上的新版本，安装包经签名校验后一键更新（菜单「Mirra › 检查更新…」）
- 录制：随时开始录制，或一键「保存刚才 15 秒」（可设 10/15/30/60 秒），带手机麦克风的声音
- 录像库：缩略图、时长，双击播放
- macOS 26 原生界面：Liquid Glass 侧边栏、悬浮控制条、设置窗口、菜单栏控制
- 之前的设置会自动迁移过来

**安装**
1. 下载 `Mirra.zip`，解压后拖进「应用程序」
2. App 没有经过 Apple 公证：第一次打开后，到「系统设置 › 隐私与安全性」点「仍要打开」
3. Mac 上需要 adb：`brew install --cask android-platform-tools`

需要 macOS 26+（Apple 芯片）和 Android 12+ 的手机。
