怎么用

两台显示器，一面镜子。

不用在墙上装镜子，也不用买新设备。一台旧手机、一根线就够了。

1

一台放跟练视频

浏览器打开你的跟练视频，照常播放。

2

一台变成镜子

Mirra 在另一台显示器上全屏显示你的画面，像镜子一样左右翻转。

3

旧手机当摄像头

手机横放、后置镜头对着你，用 USB 线连到 Mac，插上就开始。

常见问题

需要什么样的手机？

Android 12 或更高版本、摄像头能正常用的手机就可以，屏幕碎了也没关系。iPhone 暂不支持。

怎么打开 USB 调试？

在手机「设置 › 关于手机」里连续点「版本号」7 次，打开开发者选项；再到「开发者选项」里打开「USB 调试」。不同品牌的位置略有不同。第一次连 Mac 时，手机上会问「允许 USB 调试吗？」，勾选「始终允许」后点确定。

还需要装别的东西吗？

Mac 上需要 adb（Android 平台工具），装了 Homebrew 的话运行 brew install --cask android-platform-tools 即可。手机上不需要装任何 App。

第一次打开时提示「无法验证开发者」？

Mirra 目前没有经过 Apple 公证。先尝试打开一次，然后到「系统设置 › 隐私与安全性」，在页面下方点「仍要打开」。也可以下载源码自己编译。

录像存在哪里？

默认在「影片 › Mirra」文件夹，可以在设置里修改。文件是标准 MP4，任何播放器都能打开，也能直接发给朋友。

画面会上传到网上吗？

不会。画面只通过 USB 线从手机传到你的 Mac，不经过任何服务器，也不需要联网。

会自动更新吗？

会。Mirra 每天检查一次 GitHub 上的新版本，发现后提示你一键更新；在设置里打开「自动下载并安装更新」，以后就在后台悄悄完成。每个安装包都带签名，App 会先校验再安装。

可以无线连接吗？

目前只支持 USB。有线连接延迟最低，手机还能一边用一边充电。
